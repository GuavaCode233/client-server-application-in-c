R2 對已斷線的連線寫入（SIGPIPE）— server_naive
$ client 以一次 write 送出 5 行指令後立刻 close，不讀任何回覆
$ server log：
    [INFO ][647][server/server.c:438] 127.0.0.1:47512 connected (child pid=647, connfd=4)
    [INFO ][647][server/server.c:255] 127.0.0.1:47512 cmd: u
    [INFO ][647][server/server.c:255] 127.0.0.1:47512 cmd: u
$ ps --ppid 645 -o pid,stat,cmd ；並讀取殭屍的結束狀態
    PID    PPID STAT CMD
    647     645 Z+   [server_naive] <defunct>
  → 子行程 647 的 exit_code = 13 → 被信號 13 終止（PIPE）
  → 預期：log 只有 connected 與一兩行 cmd，沒有 disconnected — 子行程來不及清理就被殺掉
